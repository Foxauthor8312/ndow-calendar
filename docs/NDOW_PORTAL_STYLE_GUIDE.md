NDOW VOLUNTEER PORTAL STYLE GUIDE

DESIGN PHILOSOPHY

The portal is an operational tool, not a marketing website.

Design goals:

* Readability
* Information density
* Consistency
* Fast scanning
* Professional appearance
* Minimal visual clutter

Every screen should answer:

"What information does the user need right now?"

Avoid decorative elements that do not improve understanding.

## USER EXPERIENCE RULE

A screen should communicate its primary purpose without requiring scrolling whenever practical.

Prioritize:

Tables
Lists
Status indicators
Compact summaries

Avoid:

Large decorative cards
Excessive whitespace
Animations
Visual effects that do not convey information

---

## ARCHITECTURE RULE

Dashboard = User Information

Admin = Management Functions

System = Operational Functions

Do not mix these responsibilities.

---

## FINAL TEST

Before adding a feature ask:

"Would this look comfortable in a professional state agency application?"

If yes, it likely follows the portal style guide.
