# NDOW Demo Notes

## Purpose

This document defines the recommended demonstration flow for the NDOW Volunteer Portal.

The objective is to demonstrate a complete volunteer management platform rather than individual features.

Demonstrations should focus on solving operational challenges, reducing administrative workload, improving volunteer engagement, and providing measurable program impact.

---

# Primary Demonstration Message

The NDOW Volunteer Portal provides:

- Event visibility
- Volunteer participation tracking
- Instructor management
- Volunteer impact reporting
- Administrative oversight
- Operational automation

All within a single system.

---

# Demonstration Philosophy

Demonstrate outcomes, not features.

Avoid:

"This button does this."

Instead demonstrate:

"This reduces administrative effort and improves volunteer participation."

---

# Recommended Demonstration Flow

## 1. Volunteer Calendar

Show:

- Calendar view
- Event details
- Program information
- Event locations

Message:

Volunteers can easily find opportunities and obtain event information.

---

## 2. User Login

Show:

- Volunteer login
- User-specific access

Message:

The portal provides personalized information based on the logged-in user.

---

## 3. My Dashboard

Show:

Impact Summary

- Events
- Hours
- Mileage
- Volunteer Value

Upcoming Events

Recent Activity

Message:

Volunteers immediately see their contribution and upcoming responsibilities.

---

## 4. Event Participation

Show:

- Event detail modal
- Instructor assignments
- Primary and Assistant roles

Message:

Responsibilities are clearly defined and visible.

Primary Instructors manage event records.

Assistant Instructors participate and enter hours.

---

## 5. Volunteer Hours

Show:

- Hours entry
- Mileage entry
- Volunteer value calculation

Message:

Volunteer contributions are measurable and reportable.

---

## 6. Administrative Functions

Show:

- User management
- Volunteer approvals
- Help topic management
- Announcements

Message:

Administrative workload is centralized and simplified.

---

## 7. System Operations

Show:

System Console

- Workflow status
- Calendar update
- Event processing

Message:

Operational tasks are automated while remaining manually controllable when necessary.

# Demonstration Rule

Always answer:

"How does this help NDOW?"

before explaining:

"How does this feature work?"

Benefits should be demonstrated before implementation details.
