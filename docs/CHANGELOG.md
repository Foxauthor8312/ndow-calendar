# CHANGELOG

All notable changes to the NDOW Volunteer Portal are documented in this file.

Version numbers follow:

MAJOR.MINOR.PATCH

Examples:

1.0.0
1.1.0
1.1.1

Version Guidelines

MAJOR
Breaking changes or major platform milestones.

MINOR
New features and modules.

PATCH
Bug fixes and small improvements.
