Calendar Help

• Use the category filters to display specific event types by clicking on the legend titles. Click again to end filter. Multiple filters may be set.

• Click any event on the calendar to view additional details. A popup displays basic information and a link to view the entire event on the NDOW website.

• Some private or unlisted events require login access through the NDOW app. Login should automatically appear if required.

• The calendar updates automatically one in the late night.

• Mobile and desktop access are fully supported.

• Contact the calendar administrator via email or text on the login screen if you experience login or access issues.
